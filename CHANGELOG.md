# История изменений

## 1.1.0 — 2026-09-15

* Импорт документов из каталога на диске сервера: дерево папок становится деревом разделов
  (любой вложенности), файлы — документами; файл README/описание.txt в папке — описанием раздела.
  Страница «Импорт» в панели администратора: выбор папки в каталоге импорта (`IMPORT_DIR`),
  целевой раздел, статус и срок актуальности, предпросмотр плана, выполнение порциями с ходом
  и журналом. Повторный импорт безопасен: существующие разделы переиспользуются, неизменившиеся
  файлы пропускаются, изменившиеся получают новую версию. Режим переноса (удаление исходников).
* Консольная команда `app:import:directory` и команда управления `docportal import`.
* Параметр `IMPORT_DIR`; скрипты установки/обновления создают `shared/import`; в Docker — том
  или каталог `IMPORT_HOST_DIR`; проверка каталога в `app:check` и `docportal status`.
* Оформление значков статуса (отступ у точки), скрытие элементов с атрибутом `hidden`.

## 1.0.0 — 2026-09-15

Первый выпуск.

* Дерево разделов любой вложенности (до 10 уровней), перенос поддеревьев, порядок разделов.
* Документы двух видов: файлы (PDF, Office, чертежи, архивы и др.) и страницы (визуальный редактор Quill).
* Версии документов: история, скачивание любой версии, построчное сравнение страниц, восстановление.
* Статусы: черновик → опубликован → архив; предпросмотр PDF и изображений в браузере.
* Срок актуальности: значки состояния, ежедневная проверка, уведомления по почте ответственным и администраторам.
* Модераторы разделов с наследованием прав на подразделы; раздел администратора.
* Статистика: обзор, активность по дням и месяцам, рейтинг документов, разрезы по разделам и пользователям,
  контроль актуальности, журнал событий, выгрузка CSV; статистика по каждому документу.
* Вход по локальным учётным записям и через Active Directory / LDAP (служебная учётная запись или UPN,
  группы доступа и администраторов, автосоздание учётных записей).
* Скрипты установки, обновления с откатом, резервного копирования, восстановления, диагностики и удаления;
  Docker Compose с планировщиком; консольные команды; автотесты.
